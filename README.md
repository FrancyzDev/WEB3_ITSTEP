# Сравнение версий Web: 1.0, 2.0, 3.0

**Web 1.0 (1990-2004) - "Только чтение"**
Статичные HTML-страницы, пользователи только потребляют контент. Данные принадлежат владельцам сайтов. Пример: ранний Yahoo, персональные страницы.

**Web 2.0 (2004 - настоящее время) - "Чтение + запись"**
Пользователи сами создают контент (посты, видео, комментарии). Технологии: AJAX, API, облака, мобильные приложения. Данные централизованы на серверах корпораций (Google, Meta). Монетизация - таргетированная реклама. Проблема: пользователь создаёт ценность, но не владеет ни данными, ни прибылью.

**Web 3.0 (с 2014-2020-х) - "Чтение + запись + владение"**
Децентрализованный интернет на блокчейне. Технологии: смарт-контракты, DeFi, NFT, DAO. Пользователь через криптографические ключи сам контролирует свои данные и активы. Монетизация - токенизация, доля в создаваемой ценности.

## Таблица отличий

| Критерий | Web 1.0 | Web 2.0 | Web 3.0 |
|---|---|---|---|
| Взаимодействие | Чтение | Чтение + запись | Чтение + запись + владение |
| Роль пользователя | Пассивный потребитель контента | Создатель контента (но не владелец) | Владелец данных и активов, участник управления |
| Контроль данных | Владельцы сайтов | Корпорации | Пользователи (децентрализовано) |
| Инфраструктура | Статичный HTML | Централизованные серверы | Блокчейн, P2P |
| Пример | Yahoo (ранний) | Facebook, YouTube | Ethereum, DeFi |
