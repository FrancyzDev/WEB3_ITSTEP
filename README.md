# Блокчейн для голосування

Ідея проста: зробити так, щоб голосувати було легко, а результати не можна було підробити.

## Як дізнаються, що це точно ти

Під час реєстрації ти один раз підтверджуєш особу за паспортом чи ID-карткою - так система прив'язує до тебе унікальний цифровий ключ. Далі заходиш просто по Face ID чи відбитку пальця, без паролів. Причому система перевіряє лише те, що ти маєш право голосувати - а за кого саме ти голосуєш, ніхто не бачить.

## Голосувати - легко і швидко

Відкрив застосунок на телефоні, увійшов по біометрії, обрав варіант, підтвердив - готово. Жодних черг і паперових бюлетенів. Після голосування тобі дають код, за яким можна перевірити, що твій голос точно врахували (але не розкриваючи, за кого ти голосував).

## Чому це не підробити

Кожен голос записується в блокчейн, і його вже не можна змінити чи стерти заднім числом. За правило "одна людина - один голос" відповідає смарт-контракт: він автоматично перевіряє, чи вже голосував цей ідентифікатор, і просто не пропустить повторну спробу. А результати видно всім у реальному часі - підкрутити цифри непомітно не вийде.

## Підсумок

Виходить система, де голосувати зручно і швидко, але при цьому ніхто не може ні підробити твій голос, ні дізнатися твій вибір, ні змахлювати з підрахунком.
