# Децентрализованная соцсеть на Ethereum

**Идея:** соцсеть, где профиль, лайки, репосты, комментарии, подписки и посты принадлежат самому пользователю, а не компании.

## Учёт пользователей

Аккаунт — это кошелёк с понятным именем. В блокчейне лежат только:

- имя
- ссылка на профиль
- ключ для шифрования

## Регистрация и вход

- **Регистрация** занимает одну транзакцию
- **Вход без пароля:** пользователь подписывает сообщение кошельком
- **Временный ключ** выдаётся для мелких действий, например лайков, чтобы не подтверждать каждый клик. У него ограниченные права и срок действия

## Взаимодействия

- **Посты и комментарии** записываются в блокчейн как короткие записи со ссылкой на текст или картинку. Сами файлы лежат во внешнем хранилище.
- **Лайки, репосты и подписки** собираются пачками, и в блокчейн уходит одна «печать» на всю пачку. Так дешевле
- **Личные сообщения** зашифрованы и идут вне блокчейна
- **Донаты авторам** отправляются напрямую

## Приватность и безопасность
- Личное в открытом виде не публикуется, приватное шифруется на устройстве
- Можно иметь несколько анонимных аккаунтов
- Доступ восстанавливается через seed-фразу
